# Attack Transfer Matrix

For every imported attack, create one row per indispensable requirement.

| Source requirement | Exact source evidence | Target analogue | Status: preserved / modified / absent / unknown | Consequence for attack | Smallest decisive test or proof obligation |
|---|---|---|---|---|---|

A transfer is **exact** only when every indispensable requirement is preserved and the complete complexity is recomputed. It is **conservative** when a target difference can only weaken the attack and the bound reflects that weakening. It is **speculative** when at least one indispensable requirement is unknown or replaced by an unvalidated heuristic.
