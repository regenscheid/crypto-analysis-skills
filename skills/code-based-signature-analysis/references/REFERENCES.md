# References for Code-Based Signature Analysis

These references are starting points, not substitutes for checking the exact target version, later corrections, implementation artifacts, and subsequent cryptanalysis.

When using a reference:

- cite the exact theorem, algorithm, table, parameter set, or source-code revision used;
- preserve the source adversary model and success definition;
- distinguish asymptotic analysis, concrete estimates, and implemented results;
- search for errata, follow-up attacks, rebuttals, and revised specifications;
- record any transfer from the cited object to the current target in a transfer matrix.

## Hamming-metric code-based cryptography

- **`CFS01`** — Nicolas Courtois, Matthieu Finiasz, and Nicolas Sendrier, “How to Achieve a McEliece-Based Digital Signature Scheme,” ASIACRYPT 2001. https://doi.org/10.1007/3-540-45682-1_10
- **`STERN93-ID`** — Jacques Stern, “A New Identification Scheme Based on Syndrome Decoding,” CRYPTO 1993. https://doi.org/10.1007/3-540-48329-2_2
- **`WAVE19`** — Thomas Debris-Alazard, Nicolas Sendrier, and Jean-Pierre Tillich, “Wave: A New Family of Trapdoor One-Way Preimage Sampleable Functions Based on Codes,” ASIACRYPT 2019; IACR ePrint 2018/996. https://eprint.iacr.org/2018/996
- **`CROSS-SPEC`** — CROSS team, CROSS code-based signature specification and supporting material. https://www.cross-crypto.com/
- **`SDITH-SPEC`** — SDitH team, Syndrome Decoding in the Head specification and supporting material. https://sdith.org/
- **`DOOM11`** — Nicolas Sendrier, “Decoding One Out of Many,” PQCrypto 2011. https://doi.org/10.1007/978-3-642-25405-5_5
